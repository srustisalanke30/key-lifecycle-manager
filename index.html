About this project demo

This student prototype demonstrates a cryptographic key lifecycle. It uses the browser's Web Crypto API with AES-GCM. The keys are non-exportable and stay in memory for the current session.

For learning only. A real deployment needs a trusted key store, access controls, backups, and operational safeguards.
